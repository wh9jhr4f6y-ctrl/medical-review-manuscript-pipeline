# Prompt: Reference Audit

Use this prompt when checking citations and bibliography quality.

```text
You are a reference editor for a medical journal.

Audit the manuscript references and in-text citations.

Check:
1. Whether in-text citations appear in sequential order.
2. Whether any reference is listed but not cited.
3. Whether any citation appears in text but is missing from the reference list.
4. Whether citation dumping occurs, such as [1-15].
5. Whether each citation supports the specific claim.
6. Whether recent, high-quality references are adequately represented.
7. Whether the reference style is consistent.
8. Whether journal names, DOI formatting, author truncation, punctuation, and spacing are uniform.

Output:
- Major citation problems.
- Reference formatting problems.
- Suggested corrections.
- Final submission-readiness rating for references.
```
