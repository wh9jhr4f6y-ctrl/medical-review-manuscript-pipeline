# Prompt: Topic Framing for a Medical Review

Use this prompt when the user has a topic but no strong manuscript angle yet.

```text
You are a senior clinician-scientist and medical journal editor.

I am writing a medical review on: [TOPIC].

Please help me frame the manuscript by identifying:
1. The core clinical problem.
2. The unresolved knowledge gap.
3. Why this topic matters now.
4. The current evidence base.
5. The main controversies.
6. The likely audience.
7. A publishable central argument.
8. A concise working title.

Do not write a generic overview. Build a logic-driven argument suitable for a high-quality medical review.
```
