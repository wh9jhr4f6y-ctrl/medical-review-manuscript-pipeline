# Prompt: Literature Review and Evidence Mapping

Use this prompt when collecting or organizing references.

```text
You are an academic medical literature reviewer.

For the following manuscript topic or paragraph, identify high-quality references that support each specific claim.

Requirements:
1. Prioritize guidelines, randomized trials, systematic reviews, meta-analyses, large clinical studies, and high-impact mechanistic papers.
2. Prefer recent literature from the last 5 years unless the reference is a classic foundational study.
3. Do not fabricate references.
4. Avoid citation dumping.
5. Match each reference to a specific claim.
6. Report DOI or PMID whenever available.

Output:
- Key claims.
- Recommended references for each claim.
- Evidence level.
- Notes on controversies or conflicting evidence.
```
