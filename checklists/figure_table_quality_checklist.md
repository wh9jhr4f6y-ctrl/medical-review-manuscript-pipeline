# Figure and Table Quality Checklist

## Tables

- [ ] Each table has a clear purpose.
- [ ] The table is not a duplicate of the text.
- [ ] Columns are not overcrowded.
- [ ] Main findings are concise.
- [ ] Abbreviations are defined.
- [ ] Statistical notation is consistent.
- [ ] Table title uses journal-appropriate style.
- [ ] No unnecessary colors, shading, vertical borders, or decorative elements.

## Figures

- [ ] Each figure supports the manuscript argument.
- [ ] Figure text is readable at final publication size.
- [ ] Color choices are accessible and not overly decorative.
- [ ] Mechanism figures are not overcrowded.
- [ ] Figure legends explain all panels.
- [ ] Image resolution meets journal requirements.
- [ ] Original editable files are retained for revision.

## Common Resolution Targets

- Color or grayscale figure: at least 300 dpi.
- Combination figure: at least 500 dpi.
- Line art: at least 1000 dpi.
