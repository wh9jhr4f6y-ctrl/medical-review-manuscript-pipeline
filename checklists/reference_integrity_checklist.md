# Reference Integrity Checklist

- [ ] Are all references real and verifiable?
- [ ] Are all references cited in the manuscript?
- [ ] Are all in-text citations represented in the reference list?
- [ ] Do citations appear in order of first mention?
- [ ] Are there any long unsupported citation ranges?
- [ ] Does each citation support the exact sentence it follows?
- [ ] Are recent studies represented sufficiently?
- [ ] Are classic studies retained only when necessary?
- [ ] Are opposing viewpoints cited for controversial topics?
- [ ] Is self-citation proportionate and relevant?
- [ ] Are DOI, PMID, volume, issue, and page fields formatted consistently?
