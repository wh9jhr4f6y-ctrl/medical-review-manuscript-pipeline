# Journal Profile: World Journal of Gastroenterology-Style Reviews

Always verify the journal's current instructions before submission.

## Common Features

- Title page.
- Abstract.
- Core Tip.
- Keywords.
- Main text with clear headings.
- Numbered references.
- Tables and figures after references depending on submission system.

## Style Priorities

- Claims should be evidence-linked.
- References should be recent and representative.
- Tables should be concise and clinically useful.
- Figures should clarify mechanisms, controversies, or future directions.

## Citation Guidance

- Avoid long citation blocks.
- Keep citation order consistent.
- Ensure each paragraph contains relevant support when required by article type.
